🥕 당근마켓 전국 시세 탐지기 (Daangn Price Dashboard)

중고거래 플랫폼 당근마켓의 데이터를 분석하여 거품 없는 진짜 중고 시세를 알려주는 대시보드 웹 서비스입니다.
"미개봉", "새제품" 등 특정 조건의 상품만 필터링하여 정확한 시세를 파악하고, 실시간 '꿀매물'을 탐색할 수 있습니다.

🌟 주요 기능

전국 시세 요약: 키워드별 평균가, 중앙값(적정 시세), 최저/최고가 제공

가격 분포 히스토그램: 시세가 집중된 가격대 시각화 (Recharts)

꿀매물 필터링: 적정 시세 대비 저렴한 상위 매물 추천 및 하이라이트

📁 디렉토리 구조

.github/workflows/: 매일 자동으로 크롤러를 실행하는 GitHub Actions 설정

backend-crawler/: Playwright 기반 파이썬 데이터 수집 및 정제 봇

frontend-web/: Next.js 기반 대시보드 웹 (데이터 시각화)
